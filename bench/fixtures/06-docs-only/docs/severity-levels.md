# Severity levels

| Level | Meaning | Example | Update every |
|---|---|---|---|
| SEV1 | Customers cannot pay or log in | checkout returns errors for everyone | 30 minutes |
| SEV2 | A major feature is degraded | search is slow for one region | 60 minutes |
| SEV3 | A minor feature is broken, with a workaround | export button fails, the API works | daily |

When in doubt, pick the higher severity. You can lower it later.

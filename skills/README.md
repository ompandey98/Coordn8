# skills/

Skills that ship with Coordn8. Each skill is a directory holding a `SKILL.md` (and any supporting
files it needs). The same tree serves both install routes:

- **Claude Code plugin** (`/plugin marketplace add ompandey98/coordn8`, then
  `/plugin install coordn8@coordn8`): Claude Code scans `skills/<name>/SKILL.md` at the plugin root.
  Skills run as `/coordn8:<name>`.
- **npx install** (`npx -y github:ompandey98/coordn8 init`): the installer copies every skill
  directory into `~/.claude/skills/`. Skills run as `/<name>`.

| Path | What it is | Who writes it |
|---|---|---|
| `coordn8/SKILL.md` | The Coordn8 engine: the full brain from `engine/PLAYBOOK.md`, embedded byte-for-byte between the `COORDN8:BRAIN` markers. | Generated by `python3 build/generate_adapters.py`. Never edit by hand; `--check` fails on any drift. |
| `coordn8-*/SKILL.md` | Supporting skills, such as the automatic frame-sheet review. | Hand-written. |

The catalogs the skills use (palettes, diagram and scene types, voices and so on) live in `data/`
and are read by the scripts in `scripts/`; they are not skills.

To change the engine skill, edit `engine/PLAYBOOK.md` and regenerate.
